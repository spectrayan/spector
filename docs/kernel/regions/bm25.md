## Field Specifications

This region uses a raw `AppendMemory` serialization format without a dedicated fixed layout class. It stores opaque serialized blobs of the BM25 index structures.

## Access Patterns & Concurrency

Appended during checkpoints; read linearly during cold start initialization to reconstruct the BM25 lexical index in memory.

## Cognitive Role

Provides persistent cold-start recovery for the BM25 sparse lexical indexes, bypassing the need to re-index all episodic and semantic texts on startup.
