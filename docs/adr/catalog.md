## Thematic Categorization

### 1. Memory Storage, Panama FFM Layouts & Bundle Kernel
Decisions establishing the off-heap zero-GC memory architecture, single-VMA bundles, cache-line aligned layouts, and multi-tier partitioning:
- **[ADR-0001: Graph Compression Strategy](0001-graph-compression-strategy.md)**: Compressed Sparse Row (CSR) representation of entity graphs.
